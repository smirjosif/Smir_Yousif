ATLIQ Hospitality Data Analysis

Comprehensive Business Intelligence solution built for the hospitality industry. This project transforms raw booking and operational data into actionable insights to drive revenue optimization, occupancy improvement, and strategic decision-making.

Project Overview

The ATLIQ Hospitality Analytics initiative addresses data silos and fragmented reporting systems by creating a unified dashboard platform using Excel and Power BI. It enables stakeholders to monitor revenue, occupancy, ADR, RevPAR, and booking performance from a centralized data model.

Tools & Technologies

  • Microsoft Excel – Data Cleaning & Preparation
  • Microsoft Power BI – Data Modeling & Visualization
  • Power Query – ETL Operations
  • DAX – Advanced Calculations (26 Measures + 2 Calculated Columns)
  • Star Schema Data Modeling

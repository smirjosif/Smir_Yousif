Sales Analysis SQL Project

Project Overview

This project demonstrates SQL techniques used by data analysts to explore, clean, and analyze sales data. It includes database setup, data cleaning, exploratory data analysis (EDA), and solving business problems using SQL queries.

Database Setup

CREATE DATABASE sales_project_db;

CREATE TABLE sales_project (
    transaction_id INT PRIMARY KEY,
    sale_date DATE,
    sale_time TIME,
    customer_id INT,
    gender VARCHAR(10),
    age INT,
    category VARCHAR(35),
    quantity INT,
    price_per_unit FLOAT,
    cogs FLOAT,
    total_sale FLOAT
);

Key Business Queries

1. Total Sales Per Category

SELECT 
    category,
    SUM(total_sale) AS net_sale,
    COUNT(*) AS total_orders
FROM sales_project
GROUP BY category;

2. Top 5 Customers by Total Sales

SELECT 
    customer_id,
    SUM(total_sale) AS total_sales
FROM sales_project
GROUP BY customer_id
ORDER BY total_sales DESC
LIMIT 5;

3. Best Selling Month Per Year

SELECT *
FROM (
    SELECT 
        EXTRACT(YEAR FROM sale_date) AS year,
        EXTRACT(MONTH FROM sale_date) AS month,
        AVG(total_sale) AS avg_sale,
        RANK() OVER(
            PARTITION BY EXTRACT(YEAR FROM sale_date)
            ORDER BY AVG(total_sale) DESC
        ) AS rank
    FROM sales_project
    GROUP BY 1, 2
) t
WHERE rank = 1;

Findings

  • Identified top-performing product categories.
  • Detected high-value transactions above 1000.
  • Analyzed seasonal sales trends.
  • Discovered top-spending customers.

Conclusion

This project showcases practical SQL skills including data cleaning, aggregation, ranking, and business-driven analysis. It reflects the analytical thinking required for real-world data analyst roles.

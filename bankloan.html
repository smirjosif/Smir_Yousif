Bank Loan Report

Domain Knowledge

Bank loans are essential financial tools that help individuals and businesses meet financial goals. Banks collect loan data through loan applications, credit reports, internal systems, online portals, and third-party data sources. This data helps evaluate borrower creditworthiness and manage risk.

Process of Granting a Loan

  • Loan Application Submission
  • Application Review & Documentation
  • Identity Verification
  • Credit Check
  • Income & Employment Verification
  • Debt-to-Income (DTI) Check
  • Collateral Assessment
  • Risk Assessment
  • Approval or Denial
  • Loan Agreement & Disbursement
  • Repayment & Monitoring

Why Banks Analyze Loan Data

  • Risk Assessment – Predict default probability.
  • Decision Making – Approve or deny applications.
  • Performance Monitoring – Track loan health.

Key KPIs (SQL Server)

Total Loan Applications

SELECT COUNT(id) AS Total_Loan_Applications
FROM bank_loan;

Total Funded Amount

SELECT SUM(loan_amount) AS Total_Funded_Amount
FROM bank_loan;

Good Loan Percentage

SELECT
 (COUNT(CASE WHEN loan_status IN ('Fully Paid','Current') THEN id END)*100.0)
 / COUNT(id) AS Good_Loan_Percentage
FROM bank_loan;

Bad Loan Percentage

SELECT
 (COUNT(CASE WHEN loan_status = 'Charged Off' THEN id END)*100.0)
 / COUNT(id) AS Bad_Loan_Percentage
FROM bank_loan;

Loan Overview Analysis

Monthly Analysis

SELECT 
 MONTH(issue_date) AS Month_Number,
 DATENAME(MONTH, issue_date) AS Month_Name,
 COUNT(id) AS Total_Applications,
 SUM(loan_amount) AS Total_Funded,
 SUM(total_payment) AS Total_Received
FROM bank_loan
GROUP BY MONTH(issue_date), DATENAME(MONTH, issue_date)
ORDER BY Month_Number;

State Analysis

SELECT 
 address_state,
 COUNT(id) AS Total_Applications,
 SUM(loan_amount) AS Total_Funded,
 SUM(total_payment) AS Total_Received
FROM bank_loan
GROUP BY address_state
ORDER BY Total_Funded DESC;
